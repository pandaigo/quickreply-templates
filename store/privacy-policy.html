Privacy Policy

Last updated: May 3, 2026

QuickReply Templates ("the Extension") is a Chrome browser extension that helps users save and insert text templates.

Data Collection

The Extension does not collect, transmit, or share any personal data. Specifically:

  • No data is sent to any external server.
  • No analytics, tracking, or telemetry is included.
  • No user accounts are required.
  • No cookies are set by the Extension.

Data Storage

All user-created templates and settings are stored locally on the user's device using the Chrome Storage API (chrome.storage.local). This data never leaves the device.

Permissions

The Extension requests the following permissions:

  • activeTab — To insert template text into the currently active tab when the user selects a template.
  • contextMenus — To add a right-click menu for quick template insertion.
  • storage — To save templates and user preferences locally on the device.
  • scripting — To execute the text insertion script in the active tab.

Third-Party Services

The Extension does not integrate with any third-party services, APIs, or servers.

Changes to This Policy

If this policy is updated, the changes will be posted on this page with an updated date.
